# Sistema Geológico
Projeto acadêmico de Banco de Dados desenvolvido em SQL para gerenciamento e organização de dados de uma empresa do setor de geologia.
# Sistema Geológico

Projeto desenvolvido para a disciplina de Programação Orientada à Objetos, utilizando SQL.

O trabalho consiste na criação de um banco de dados para um sistema relacionado à área de geologia, envolvendo informações sobre geólogos, pedras, pesquisas e usuários.

## Arquivos

* `sistema_geologico_geologo.sql`
* `sistema_geologico_pedra.sql`
* `sistema_geologico_pesquisa_geologo.sql`
* `sistema_geologico_usuario.sql`

## Tecnologias

* SQL
* Banco de dados relacional

Projeto desenvolvido durante a graduação em Ciência da Computação.
